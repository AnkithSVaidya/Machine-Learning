This project performs analysis and trains models on the data for HealthGuard Insurance. The dataset can be downloaded from https://www.kaggle.com/datasets/mirichoi0218/insurance. 

Run the notebook by pressing the Run All button at the top after installing Python and all relevant libraries.

The Decision Tree was found to be the best model, with an R^2 value of 0.8641. Smoking was found to be the most significant factor to medical costs.
